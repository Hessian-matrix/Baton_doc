# 产品组成与数据链路

## 产品组成

| 设备 | 主要作用 | 用户需要确认的内容 |
| --- | --- | --- |
| VIObot2 Lite | 提供视觉定位、Web 配置和飞控接入 | 安装方向、网络、两个串口连接 |
| RTK D20 | 提供高精度 GNSS 定位 | 天线安装、差分状态、串口输出和波特率 |
| 飞控 | 融合视觉与 RTK 信息并执行飞行控制 | MAVLink 串口、估计器、遥控器与安全配置 |
| 地面站 | 配置飞控并检查定位状态 | ArduPilot 使用 Mission Planner，PX4 使用 QGroundControl |

## 对外数据关系

```text
RTK D20 ──串口──> VIObot2 Lite ──MAVLink2──> 飞控
                         │
双目相机 ──视觉定位──────┘
                         │
                    Web 控制台
```

- D20 向 Lite 提供 RTK 定位数据。
- Lite 根据双目图像和 IMU 计算视觉定位结果。
- Lite 通过一个双向 MAVLink2 串口向飞控提供视觉与 RTK 定位信息，同时读取飞控状态。
- Web 控制台用于配置、状态观察、数据记录和飞控接入操作。

## 功能边界

- D20 的差分账号、NTRIP、LoRa 和接收机输出设置应在 D20 配套工具中完成。
- Web 控制台不替代飞控的机架、IMU、罗盘、遥控器、电机和失效保护初始化。
- Web 中显示“正在转发”只说明 Lite 到飞控的发送链路正常；飞控是否接收并采用定位信息，仍需在地面站和飞控日志中确认。
- RTK 外参用于描述 D20 与左目相机的安装关系。飞控自身的天线杆臂补偿应按飞控坐标系单独填写，不能直接复制。

## 版本记录

每次飞行测试应记录以下信息，便于复现和比较：

- Lite 系统与 Web 页面显示的软件版本。
- D20 固件、输出频率和差分方式。
- 飞控型号、固件版本和完整参数备份。
- 相机安装方向、RTK 外参和实际接线端口。
