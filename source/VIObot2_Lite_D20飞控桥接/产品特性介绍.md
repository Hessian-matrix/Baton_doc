# 产品特性介绍

**VIObot2 Lite + RTK D20** 是面向无人机定位与导航的一体化视觉融合 RTK 方案。VIObot2 Lite 提供双目视觉惯性定位，RTK D20 提供高精度全局定位，两类信息经 MAVLink2 接入 ArduPilot 或 PX4 飞控。

## 核心特性

| 项目 | 能力 | 说明 |
| --- | --- | --- |
| 视觉定位 | 双目视觉惯性定位 | 在 GNSS 遮挡或短时失效时保持局部定位连续 |
| RTK 定位 | 厘米级定位能力 | 实际精度取决于差分状态、卫星环境和安装条件 |
| 定位融合 | 视觉与 RTK 协同 | 同时兼顾全局位置与连续运动信息 |
| 飞控支持 | ArduPilot、PX4 | 分别支持 EKF3 ExternalNav 与 EKF2 External Vision 接入 |
| 通信接口 | MAVLink2 | 推荐串口速率 921600 bps |
| 配置方式 | Web 控制台 | 提供中文配置、状态检查、数据记录和飞控配置模板 |
| 最大应用高度 | 60 m | 必须完成对应机型、环境和任务条件下的分级飞行验证 |

> 60 m 是组合方案的目标应用高度，不代表任意机型、任意环境均可直接达到。实际飞行高度受法规、飞控状态、相机成像、RTK 质量、振动和环境纹理影响。

## 定位与通信参数

| 项目 | 推荐配置 | 使用说明 |
| --- | --- | --- |
| D20 定位输出 | 5 Hz 或 10 Hz | 以 D20 实际输出频率为准 |
| D20 串口 | 115200 bps，8N1 | 在 Web 的“RTK 波特率”（`rtk_baudrate`）中保持一致 |
| Lite 到飞控 | MAVLink2，921600 bps | 飞控对应 UART 必须使用相同协议和波特率 |
| 相机安装 | Type-C 朝向机头 | 在 Web 的“相机安装方向”（`camera_orientation`）中选择实际方向 |
| RTK 外参 | 相对左目相机测量 | 平移单位为米，坐标方向为右、下、前 |
| 飞控 GPS 类型 | MAVLink GPS | ArduPilot 常用 `GPS1_TYPE=14`，具体名称以固件显示为准 |

## Web 控制台能力

Web 控制台默认地址为 `http://192.168.1.10:8081/`，提供以下用户功能：

- 在“算法与 VIO 控制”中选择算法、里程计来源和相机安装方向。
- 在“GPS 与 RTK”中设置 RTK 串口、波特率和安装外参。
- 在“飞控配置”中探测并应用 ArduPilot EKF3 接入模板。
- 在“桥接程序状态”中查看 RTK 输入、定位转发频率和转发延迟。
- 控制“ROS 数据录包”和“RTK 串口原始数据”的开始、停止与下载。

## 飞控兼容性

| 能力 | ArduPilot / ArduCopter | PX4 |
| --- | --- | --- |
| 视觉定位 | EKF3 ExternalNav | EKF2 External Vision |
| RTK 定位 | MAVLink GPS 后端 | GNSS 与 EKF2 融合 |
| Web 飞控配置模板 | 支持 | 当前需在 QGroundControl 手动配置 |
| 定位来源选择 | EKF 来源组与 RC 通道 | PX4 原生融合与失效保护策略 |
| 地面站 | Mission Planner | QGroundControl |

不同飞控固件版本的参数名称和枚举可能不同。首次适配必须导出完整飞控参数，并通过地面动作、低高度飞行和飞控日志完成验收。

## 适用场景

- 室外无人机的高精度定位与航点飞行。
- GNSS 信号不稳定区域的视觉连续定位。
- 视觉与 RTK 融合算法验证。
- 需要 ArduPilot 或 PX4 外部定位输入的科研与工程项目。

本方案不替代飞控基础初始化、机架调试、传感器校准、失效保护配置和飞行安全评估。
