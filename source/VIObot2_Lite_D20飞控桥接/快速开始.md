# 快速开始

本页用于完成 VIObot2 Lite、RTK D20 与飞控的首次连通和地面验收。

> **安全提示：** 首次接线和联调必须拆除螺旋桨。所有设备断电后再接线，不得仅按线色判断电压和引脚。

## 1. 安装并接线

1. 将 D20 接到 Lite 的 `ttyS3`，TX/RX 交叉连接并可靠共地。
2. 将 Lite 的 `ttyS4` 接到飞控的 MAVLink UART，只连接 TX、RX 和 GND，不连接飞控端的 5 V。
3. Lite 默认按 **Type-C 朝向机头** 安装；D20 安装在天空视野开阔且远离强电磁干扰的位置。
4. 测量 D20 定位参考点相对于 Lite 左目相机原点的位置。

详细引脚和坐标定义见[安装与接线](安装与接线.md)。

## 2. 准备 D20

完成 D20 的差分与串口输出配置，确认定位状态和实际输出频率符合任务要求。D20 的设置方法见 [RTK D20 文档](https://hm-rtk-serials.readthedocs.io/zh-cn/latest/index.html#)。

## 3. 初始化飞控

先使用 Mission Planner 或 QGroundControl 完成飞控自身的基础初始化，包括机架、传感器、遥控器、飞行模式和失效保护。为 Lite 预留一个双向 UART，并配置为：

- 协议：MAVLink2
- 波特率：921600 bps

飞控串口必须先配置正确，Web 才能连接飞控和读取参数。

## 4. 配置 Lite

电脑与 Lite 处于同一网段后，访问：

```text
http://192.168.1.10:8081/
```

在 Web 控制台依次完成：

1. 在“基础连接”中确认“FCU 串口”（`connection_string`）和“串口波特率”（`connection_baudrate`）。
2. 在“算法与 VIO 控制”中确认“相机安装方向”（`camera_orientation`），按实际安装方向调整相机方向，其他配置保持出厂默认即可。
3. 在“GPS 与 RTK”的“RTK 配置”中开启“启用 RTK 输入、NMEA/外参发布及 GPS 转发”（`enable_rtk`）。
4. 确认“RTK 串口”（`rtk_port`）与“RTK 波特率”（`rtk_baudrate`），并按实测结果填写 RTK 外参。
5. 点击“校验”，确认无错误后点击“保存并重启”。

字段解释见[Lite 与 Web 配置](Lite与Web配置.md)。

## 5. 配置飞控接入

ArduPilot/ArduCopter 用户进入 Web 的“飞控配置”：

1. 选择“EKF3 来源模板”。
2. 选择“EKF 来源切换 RC 通道”和“安全模式 RC 通道”，两个通道不得相同。
3. 保持飞控未解锁，点击“探测当前配置”。
4. 检查待修改项和综合判定后，点击“备份并应用配置”。
5. 下载修改前、修改后的参数备份，并按页面提示重启飞控和 Lite 的飞控接入功能。
6. 再次执行“探测当前配置”，确认所有项目通过。

PX4 当前不使用 Web 模板，应在 QGroundControl 中按[飞控配置](飞控配置.md)手动设置。

## 6. 地面验收

在 Web 首页确认：

- “RTK 功能开关”为开启状态。
- RTK 串口输入、NMEA 发布、外参发布和 GPS 转发均为正常状态。
- “实时频率”与 D20 实际输出频率接近，“转发延迟”稳定。
- “ROS 数据录包”和“RTK 串口原始数据”可以开始、停止和下载。

随后在地面站确认飞控持续显示有效 GPS 和视觉定位状态。静止及缓慢移动设备，检查位置、速度、姿态和各轴方向。

完整步骤见[联调与飞行前验收](联调与飞行前验收.md)。

## 7. 首飞前

确认 Home 已建立、估计器健康且没有解锁告警。首次飞行应在受控场地从低高度开始，并保留人工接管和切回已验证定位来源的能力。

> Web 中的转发状态不能代替飞控验收。是否采用定位信息必须以地面站状态和飞控日志为准。
