# Lite 与 Web 配置

## 访问控制台

Lite 出厂 IP 为 `192.168.1.10`。电脑设置同网段地址并确认网络连通后，在浏览器访问：

```text
http://192.168.1.10:8081/
```

普通用户可完成日常配置、状态检查和数据记录；高级调试参数仅对管理员开放。

## 页面功能

| 页面或分组 | 主要用途 |
| --- | --- |
| 桥接程序状态 | 查看 RTK 链路状态、实时频率、转发延迟和记录状态 |
| 基础连接 | 设置飞控串口与波特率 |
| 算法与 VIO 控制 | 选择算法、里程计来源、相机方向和常用控制功能 |
| GPS 与 RTK | 设置 RTK 输入、串口、波特率和安装外参 |
| 飞控配置 | 探测并应用 ArduPilot EKF3 接入模板 |
| ROS 数据录包 | 查看、停止和下载飞行测试记录 |
| RTK 原始字节日志 | 查看、停止和下载 D20 原始记录 |

## 基础连接

| Web 项 | 英文配置项 | 产品基线 | 说明 |
| --- | --- | --- | --- |
| FCU 串口 | `connection_string` | `/dev/ttyS4` | Lite 连接飞控的串口 |
| 串口波特率 | `connection_baudrate` | `921600` | 必须与飞控 UART 一致 |

同一串口不能同时连接其他设备或被其他应用使用。

## 算法与 VIO 控制

| Web 项 | 英文配置项 | 使用建议 |
| --- | --- | --- |
| VIO 算法 | `vio_algorithm` | 使用产品当前配套算法，常规用户保持默认 |
| 里程计输入话题 | `odometry_topic` | 默认选择“融合里程计话题”；仅专项测试时选择原始视觉里程计 |
| 相机安装方向 | `camera_orientation` | 按相机 Type-C 与机头的实际关系选择 |
| 视觉 MAVLink 输出 | `vision_mavlink_output_mode` | 常规使用保持 `odometry` |
| 上报跟踪置信度 | `enable_update_tracking_confidence_to_gcs` | 建议保持开启，便于地面站查看视觉质量 |
| VIO 激活时录包 | `enable_start_rosbag_when_vio_source_active` | 需要自动保留飞行测试数据时开启 |
| RC 控制 VIO | `enable_vio_ctrl_by_rc` | 使用 ArduPilot RC 来源切换时按模板要求开启 |
| EKF source 驱动 VIO | `enable_vio_ctrl_by_ekf_source_truth` | 仅在飞控已完成配套设置时开启 |

修改“VIO 算法”或“里程计输入话题”后，必须在状态页和地面站确认视觉定位恢复正常。下拉框选中某个选项不等于飞控已经采用该数据。

## GPS 与 RTK

“GPS 与 RTK”页面分为“GPS 转发控制”和“RTK 配置”。日常安装主要使用“RTK 配置”；“GPS 转发控制”用于开发诊断，普通用户保持默认。

### 日常配置

| Web 项 | 英文配置项 | 产品基线 | 说明 |
| --- | --- | --- | --- |
| 启用 RTK 输入、NMEA/外参发布及 GPS 转发 | `enable_rtk` | 开启 | RTK 功能总开关，正常部署必须保持开启 |
| 记录 RTK 串口原始字节流 | `enable_rtk_raw_log` | 按需 | 控制上电后是否自动记录原始数据，不影响定位转发 |
| RTK 串口 | `rtk_port` | `/dev/ttyS3` | D20 连接的串口 |
| RTK 波特率 | `rtk_baudrate` | `115200` | 必须与 D20 一致 |
| 外参平移 X/Y/Z | `rtk_extrinsic_x/y/z` | 实测值 | D20 定位参考点相对左目的位置，单位为米 |
| 外参四元数 W/X/Y/Z | `rtk_extrinsic_qw/qx/qy/qz` | `1/0/0/0` | D20 相对左目的姿态，顺序为 WXYZ |

页面中的示意图给出了左目坐标方向：`+X` 向右、`+Y` 向下、`+Z` 向前。默认零平移不代表已经完成测量。

### 状态含义

在“桥接程序状态”的“RTK 转发状态”中检查：

| 状态项 | 通过条件 |
| --- | --- |
| RTK 功能开关 | 显示开启 |
| RTK 串口输入 | 显示已连接且持续有数据 |
| NMEA 发布 | D20 开启 NMEA 输出时显示正常 |
| 外参发布 | 显示正常 |
| GPS 转发 | 显示正在转发 |
| 实时频率 | 与 D20 实际定位输出频率接近 |
| 转发延迟 | 数值稳定，无持续增长 |

“正在转发”只表示 Lite 已向飞控发送定位数据，不表示飞控估计器已经采用。最终结果必须在 Mission Planner 或 QGroundControl 中确认。

## 飞控配置

“飞控配置”用于 ArduPilot/ArduCopter EKF3 接入。依次选择“EKF3 来源模板”“EKF 来源切换 RC 通道”和“安全模式 RC 通道”，然后执行：

1. “探测当前配置”。
2. 检查综合判定与待修改项。
3. 保持飞控未解锁，执行“备份并应用配置”。
4. 下载修改前和修改后的参数备份。
5. 重启飞控，并点击顶部“重启 Bridge”。
6. 再次探测确认。

PX4 当前不使用该模板。

## 保存和生效

- “校验”检查当前填写内容，但不保存。
- “保存配置”保存修改，需稍后通过顶部“重启 Bridge”生效。
- “保存并重启”保存修改并立即重启飞控接入功能。
- 顶部“重启 Bridge”用于未修改参数时单独重启。

重启会中止正在进行的记录。操作前应先在状态首页停止“ROS 数据录包”和“RTK 串口原始数据”。

## 数据记录

状态首页可分别控制：

- “ROS 数据录包”：记录视觉、RTK 和外参等联调数据。
- “RTK 串口原始数据”：记录 D20 的原始串口数据。

进入对应列表页可查看记录编号、状态、更新时间和大小。正在记录的数据应先点击“停止”，完成后再下载。序号可用于在设备时间不准确时判断记录先后。

飞行测试前建议同时开始两类记录，落地后先正常停止，再断电。

## 管理员参数边界

普通页面仅提供安装和日常运行所需参数。管理员页面中的消息频率、超时、航向对齐门限和诊断选项用于专项调试，不应为了消除告警随意修改。出现异常时应先保留 Web 状态截图、两类记录和飞控日志。
