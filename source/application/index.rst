HM Inside 应用
======================================

本栏目介绍基于 VIObot2 的定位、建图、规划与感知能力，以及这些能力在机器人应用中的组合方式。

核心能力
----------------

- HM Localization 提供视觉定位与重定位能力。
- HM Mapping 和 HM Planner 支持环境建图、路径规划与全覆盖作业。
- 双目深度与图像分割为避障和场景感知提供数据基础。
