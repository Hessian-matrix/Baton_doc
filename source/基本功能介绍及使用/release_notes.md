# Update Firmware / Versions

Connect the device with the client UI:

![](image/image_G7ZMAy8yDt.png)

## 1. Check Current Device Version

Click **Settings**, then open the **Version** tab.

![](image/image_dkr5iuuWG0.png)

## 2. Check the Latest Version on the Website

Go to the [Hessian Matrix Download Center](https://www.hessian-matrix.com/下载中心/). Scroll to the bottom to find the latest firmware version.

![image-20250225144021973](image/image-20250225144021973.png)

If the website version is newer than your device version, download the update file. Extract it and obtain `update.tar`, then save it locally.

## 3. Update

On the Version page, click **Open Update File** and select `update.tar` to upload it to the device. Upload progress is shown. If upload fails or stalls, it may be due to unstable network; click **Stop Upload** and retry.

![](image/image_fwxJ-k8c4G.png)

![](image/image_j0YiSdtAfr.png)

After it shows completed, click **Online Update** to start the update process. After the update finishes, the device will reboot automatically.

After reboot, check the version again. If it changes to the new version, the update is complete.

![](image/image_WwtLz6JylV.png)
