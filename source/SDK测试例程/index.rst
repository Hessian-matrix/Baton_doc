SDK 使用教程
======================================

本栏目面向不依赖 ROS 的应用开发，说明如何通过 VIObot2 SDK 读取状态与流数据、管理参数并控制设备功能。

开发要点
----------------

- HTTP 服务默认使用 ``8000`` 端口。
- 支持状态查询、参数读写和算法数据获取。
- 提供 Windows 与 Linux 环境下的示例程序。
